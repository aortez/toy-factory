# Productive daylight spending comparison protocol

Test the single afternoon correction declared in the daylight audit. Does removing
credit for globally unproductive late light help the remaining failure without
losing the four surviving checks? This selected panel is a diagnostic experiment,
not training or fresh population qualification.

## Fixed treatment and panel

Control is the continuous-energy candidate. Both arms retain the birth-time root
purchase, continuous protection of only the named living offspring, first-day
water guard, stored-energy condition for afternoon maintenance increases, prices,
priorities, destinations, memory and RNG behavior. No protection for additional
plants or descendants, no dawn buffer, no resource subsidy or altered ecology.

For a paid action at phases 64 through 127, let B(q) be the unscaled daily sun
curve minus ambient 24, and C be currently observed sun strength minus 24.
Estimate later strength as `24 + floor(B(q) * C / B(now))`, q from now+1 through
127. Count estimates at least 64; use half the current income over only those
steps, rounded down. Current globally dim afternoon light has zero useful steps.
This is exactly the audit's one diagnostic, without parameter tuning or future
weather/body/income observations. Morning and night rules remain unchanged.
Use the original projected-sunset cap, post-action maintenance and night costs.

Implement this as an extra, tighter eligibility check; the original forecast
stays visible and unchanged. Nonapplicable actions have no extra restriction.
