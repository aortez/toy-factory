# Frozen landing-controller validation protocol

Fixed before collecting this panel's outcomes. Development validation only:
these worlds are not a final untouched test set after inspection. No training,
finalist reselection, promotion, ecology changes, or device changes in this step.

For each current finalist also derive an off model; for each history finalist
derive current and off models. Derivation changes only the canonical mode byte
and outer CRC. All weights, legacy bytes and other feature configuration remain
identical. Never silently override a loaded model. Include the pilot's original
pretrained controller, imported with off mode and zero extension, as baseline.
That gives **19 variants**: baseline + three off + six current + nine history.

## Fixed panel and scoring

Four additional seeds, generated by `trial_seeds(0x6c616e64, 4)`:
`25185eeb`, `d60c94c0`, `8377cb18`, `30358096`. They exclude the pilot's training
and review seeds. Cross each with rainfed/rainfed-crowded and steady/seasonal:
**16 conditions**, **304 primary evaluations**. These seeds vary the world and
weather together, not weather independently of initial conditions.

Retain ordinary production ecology (256 nodes, 8 plants, 8 seeds), gardener and
irrigation off, every research ecology flag off, and the unchanged 192-day
horizon (737280 logic ticks). Use the existing individual bounded-renewal
objective and its four windows `(62,94]`, `(94,126]`, `(126,158]`, `(158,190]`
with two-day follow-up, one-day child confirmation and 32-day credit cap.
No new scalar fitness or early stopping. Retain complete lineages and seed
receipts and rescore them with the established validator.

Repeat all 304 evaluations using one worker instead of two, with capture off;
require identical complete results and derived model bytes. Snapshot/hash the
binary, build options, source, protocol and inputs before collection and require
no changes during it. An incomplete/mismatched bundle is not evidence.

## Comparisons and visual review

- Within each controller: current versus off; history versus current and off.
  These are paired same-weight input ablations, not retrained controls.
- Between training arms: original current/history versus original off for each
  matching search seed, and each original finalist versus the initial baseline.
- Retain per-condition/window results, aggregate lexicographic keys, paired
  wins/ties/losses, established endpoint counts, zero-credit windows and worlds
  with credit in all four windows. Also report by world seed, climate and layout.
- Prespecified gallery: first seed `25185eeb`, seasonal, both layouts, days 16
  and 192, for **all 19 variants (76 frames)**. Capture independently from reset;
  require day-192 result equality with the corresponding headless evaluation.
  Inspect all contact sheets, including failures. No best-looking frame selection.

A loss after ablation demonstrates dependence on the removed inputs under this
intervention, not optimal use of dynamic sensing: zeroing features also shifts
activation distributions. Training-arm comparisons also differ in effective
search dimension. Do not conclude that history is inherently useless or that
populated screenshots establish sustained renewal. Stop after this panel,
repeat, replay verification and review; discuss the next experiment first.
