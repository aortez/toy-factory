This archive preserves the experiment chronology previously embedded in the
[A-life roadmap](garden-alife-roadmap.md). It is historical evidence, not the
current task list. References below to "next", "now", uncommitted work and test
counts describe their original checkpoints; they do not assert today's git or
validation status.

For the current scope, conclusions and review boundary, start with the
[adult resources and renewal checkpoint](garden-adult-resources-checkpoint.md).

acceptance gates. No experiments or negative results were discarded in this move.
